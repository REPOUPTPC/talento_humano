1. Descargar Plantilla / Datos Activos

Descarga los registros actuales en formato CSV para editarlos offline en Excel o Calc.

Columnas: Cedula, Nombre, Categoria, Cargo, Desde, RemuneracionMensual, Status
2. Reglas de Validación de CSV
  • Decimales: Usar punto . (ej: 1250.50). Sin comas ni símbolos como $ o Bs.
  • Fechas: Formato DD/MM/AAAA (ej: 30/12/2026).
  • Auto-Formato: Si la Cédula es numérica (ej: 12121212), el sistema le antepondrá V-12121212.
  • Mayúsculas: Todos los textos se convertirán automáticamente a MAYÚSCULAS.
  • Código: Se generará automáticamente el código alfanumérico único para cada expediente.
