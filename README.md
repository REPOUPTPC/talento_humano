# Sistema de Consulta y Gestión de Expedientes

## Descripción
Este proyecto corresponde a una aplicación web sencilla para la consulta, edición individual y gestión masiva de expedientes de personal. Está diseñada para funcionar como una interfaz de usuario frente a Google Sheets mediante Google Apps Script, permitiendo consultar información y actualizar registros de forma práctica.

## Funcionalidades
- Consulta individual de expedientes por cédula y fecha de ingreso.
- Edición de registros de forma individual.
- Edición masiva desde una tabla interactiva.
- Integración con Google Sheets a través de una URL de Apps Script.
- Modo de demostración offline con datos locales para pruebas.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript vanilla
- Bootstrap 5
- Google Apps Script

## Estructura del proyecto
- `index.html`: estructura principal de la interfaz.
- `app.js`: lógica de la aplicación, consultas, edición y conexión con Google Sheets.
- `logo.jpg`: imagen institucional utilizada en la interfaz.
- `LICENSE`: licencia del proyecto.

## Requisitos
- Un navegador moderno.
- Opcionalmente, una URL de una aplicación web publicada en Google Apps Script para conectar con Google Sheets.

## Uso
1. Abrir el archivo `index.html` en el navegador.
2. Si se desea usar datos reales, ir a la pestaña de "Conexión a Google Sheets" y configurar la URL de la aplicación web.
3. Si no se tiene conexión configurada, la aplicación podrá funcionar en modo demostración con datos de ejemplo.

## Instalación y despliegue
Este proyecto puede ejecutarse de forma local directamente en el navegador. También puede desplegarse en GitHub Pages si se desea publicar la interfaz web.
